# Optional launch film

Place the final MP4 at `public/media/launch-film.mp4` and build with `VITE_LAUNCH_FILM_URL` set as shown in `.env.example`.

Delivery requirements:

- 6–8 seconds, one continuous shot;
- H.264 MP4, muted, 1920×1080;
- target 3–6 MB;
- include a clean first frame so the browser can display it immediately;
- no embedded labels that duplicate dashboard UI;
- the interface shows it once per browser session, includes a skip action, and suppresses it when reduced motion is enabled.
